EXECUTION RELIABILITY & INTEGRITY

动作账本与容灾自愈状态机

每一次本地调用都在 SQLite WAL 中留存不可篡改的凭据。
即使操作系统突发断电或网络中断，Nexus 亦能自动恢复状态，杜绝任何二次副作用。

Action Ledger 预写事务日志 (WAL)

Write-Ahead Logging · Immutable Receipts

在向 Windows 触发任何物理操作（写文件、发指令、起进程）之前，Nexus 会先在本地 WAL 账本中写入一条带幂等键（Idempotency Key）的预备记录。完成后记录退出码、真实文件哈希与窗口句柄。

ACTION #1842 · VERIFIED COMMITTED
TOOL: filesystem.write_file
PATH: C:\Workspace\docs\Architecture_Spec.docx
SHA256: 9b4a1c7e283d5f... (Validated)
EVIDENCE: File exists (size: 48,920B, attr: ARCHIVE)

Durable Execution 容灾自愈状态机

Zero Side-Effects · Crash Recovery

当子进程意外死亡或宿主机断电重启时，看门狗读取 WAL 账本。Nexus 拒绝直接盲目重放，而是先发起物理状态探测（探查文件是否已落盘、句柄是否活跃），确认事实状态后再进行幂等确认或安全回退。
