Tool Registry (工具注册中心)

严格遵循 JSON Schema Draft 7 规范定义工具契约。支持动态元数据反射、参数强类型预校验、风险分级与版本化工具遮蔽。

SCHEMAS: Validated · DISCOVERY: Dynamic · CONTRACT: Strict

Provider Layer (设备驱动分发)

统一抽象多源操作系统设施。根据任务类型自动将 MCP 调用路由至 Win32 驱动、WinRT UI 自动化、无头/有头浏览器 CDP 或 Office 解析引擎。

DRIVERS: Win32 · WinRT · CDP · DOCX · Native Shell

Runner (隔离执行器)

采用 Windows JobObject 硬隔离机制。对每个生成的命令实施 CPU 配额、最大物理内存限制、孤儿进程秒级杀死与环境安全擦除。

SANDBOX: JobObject · MEM_CAP: 4GB · TIMEOUT: Monitored

Action Ledger (事务日志账本)

Append-only 预写式事务日志系统（WAL）。记录所有动作的入参签名、时间戳、执行物理耗时、输出哈希与对应幂等键，提供法证级审计。

STORAGE: SQLite WAL · INTEGRITY: SHA-256 · ATOMIC: Yes

Computer State (系统状态感知)

高频感知 Windows 系统状态变迁。维护活动 HWND 窗口列表、Z 序焦点、前台进程占用、受锁文件列表与屏幕渲染差分树。

HWND: Tracked · FOCUS: Active · UI_TREE: Cached

Verification (物理真值断言)

独立于工具自身的二阶段验证器。通过向 OS 重新发起系统调用（检查目标文件字节数与哈希、检查进程退出代码、断言 DOM 存在性）验证结果。

PROBES: Native Syscall · ZERO_TRUST: Enforced
Action Ledger Deep Dive

Every Action Leaves Evidence.
