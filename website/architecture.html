Every Action Leaves Evidence.

Execution ≠ Success=true. True reliability requires Execution + Evidence + World State + Verification.

Execution ≠ Success=true
Execution + Evidence + World State + Verification = Certified Reality

Before any action mutates the physical operating system, it is pre-registered in the SQLite WAL ledger. Upon completion, low-level OS probes extract ground-truth evidence—including actual file SHA-256 hashes, live process PIDs, and active window handles (HWND).
