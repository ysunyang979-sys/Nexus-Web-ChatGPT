Computer Control (桌面与视觉自动化)

基于 WinRT 原生 OCR 与系统 UI Automation 无障碍树，取代粗糙脆弱的纯坐标点击，实现对 Windows 屏幕与窗口的精准感知与交互。

Desktop (多屏桌面截屏)
Mouse (移动/点击/拖拽)
Keyboard (按键/快捷键序列)
Screenshot (ROI区域截图)
Vision (多模态视觉确认)
OCR (WinRT 本地离线识别)
Window Control (HWND置顶/切换)
TOOL SCHEMA: computer.interact TYPE: WIN32_INPUT 
{
  "name": "computer.window_action",
  "parameters": {
    "action": "focus_and_click",
    "target": {
      "hwnd": "0x002B0F12",
      "element_role": "Button",
      "text_anchor": "Render Frame"
    },
    "verify": {
      "assert_window_foreground": true,
      "timeout_ms": 3000
    }
  }
}

Filesystem (规范路径文件系统沙箱)

强制通过操作系统原生真实规范路径校验，物理防御目录跨越、符号链接软链接逃逸与 Windows NTFS Junction 越权访问。

Read (受限分块读取)
Write (原子写与临时落地)
Copy (全量或增量复制)
Move (原子重命名与移动)
Delete (受控移除并入回收站)
Search (全文/文件名极速索引)
Verify (SHA-256完整性校验)
TOOL SCHEMA: filesystem.write TYPE: ATOMIC_IO 
{
  "name": "filesystem.atomic_write",
  "parameters": {
    "path": "workspace/src/config.ts",
    "content": "export const CONFIG = {...};",
    "atomic_temp": true,
    "verify": {
      "expected_sha256": "8a3f9c...",
      "assert_permissions": "0644"
    }
  }
}

Runtime (系统进程与开发运行时)

提供有状态伪终端会话（PTY）与长作业后台托管，受 Windows JobObject 硬隔离监控，支持资源配额控制与异常自杀机制。

Process (JobObject子进程生成)
Shell (有状态流式PTY会话)
Environment (受控环境变量隔离)
Services (Windows服务状态监控)
Runtime Discovery (Node/Python/Rust环境嗅探)
TOOL SCHEMA: runtime.spawn TYPE: JOBOBJECT_EXEC 
{
  "name": "runtime.process_spawn",
  "parameters": {
    "command": "cargo test --workspace",
    "limits": {
      "max_memory_mb": 4096,
      "cpu_rate_pct": 80,
      "timeout_sec": 300
    },
    "capture": ["stdout", "stderr", "exit_code"]
  }
}

Browser (高保真 Chromium 自动化)

直接挂载 Chrome/Edge DevTools 协议（CDP），支持无头或有头模式下的动态页面导航、元素交互、状态抓取与完整网络流审计。

Navigate (页面导航与网络空闲等待)
Click (真实物理或DOM点击)
Input (按键键入与表单填充)
Extract (DOM树与语义提取)
Screenshot (全页/元素级截屏)
Browser State (Cookie/Storage校验)
TOOL SCHEMA: browser.navigate TYPE: CDP_SESSION 
{
  "name": "browser.navigate_and_extract",
  "parameters": {
    "url": "https://localhost:3000/dashboard",
    "wait_until": "networkidle0",
    "extract_selector": "table.telemetry",
    "verify": {
      "assert_http_status": 200,
      "assert_element_visible": "#app-ready"
    }
  }
}

Applications (本地软件发现与深度控制)

对本地安装的第三方生产力与工程软件（Blender, VSCode, Office, Terminal）进行系统级进程唤醒、HWND 句柄绑定与生命周期收拢。

Launch (带参静默或界面拉起)
Close (优雅保存或强制退出)
Control (HWND发送消息/IPC控制)
App Discovery (本地注册软件嗅探)
TOOL SCHEMA: application.launch TYPE: WIN32_PROCESS 
{
  "name": "application.launch",
  "parameters": {
    "app_name": "blender.exe",
    "work_dir": "C:/Projects/3DScene",
    "args": ["--python", "scripts/build_mesh.py"],
    "verify": {
      "assert_window_spawned": true,
      "target_window_title_pattern": "Blender.*"
    }
  }
}

Documents (工业级 Office 文档工程)

原生构建与解析 DOCX, XLSX 等复杂 OpenXML 格式文档，支持精准样式表注入、表格与多级目录生成，杜绝格式破碎与文件损坏。

DOCX (OpenXML规范创建与修改)
Files (复杂格式流式打包与解构)
Office Workflows (跨组件批处理)
