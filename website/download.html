Quick Onboarding

3 步极简上手，开启本地 AI 研发

无需安装复杂的 Python 或 Docker 依赖，纯原生桌面端开箱即用。

01

运行 Nexus 桌面控制中心

双击启动安装好的 Nexus 应用程序。系统托盘将常驻运行图标，本地高性能 Fastify MCP 协议服务器与 Runner 守护进程将自动于 127.0.0.1:18080 建立安全隔离信道。

02

授权受保护的开发项目目录

在 Nexus 桌面界面的「已授权项目」中添加你允许 AI 接触的代码仓库。底层采用 fs.realpathSync.native 物理规范路径锁死沙箱，默认阻断一切符号链接绕过与敏感密钥（.env / *.pem）。

03

填入 ChatGPT 或 Claude

在「令牌管理」生成高熵 Client Token（lb_xxx），将端点 http://127.0.0.1:18080/mcp 添加到 ChatGPT Web / Desktop 或 Claude Desktop，即可直接召唤 332 个本地开发工具！

Troubleshooting

首次安装启动避坑指南

针对操作系统安全策略与未签名提示的快速处置说明。

Windows 10/11

Microsoft Defender SmartScreen 提示“未知发布者”

开源社区版为了保持永久免费未购买微软数千美元的商业 EV 签名证书。在 Windows 10/11 上首次启动安装包时若弹出蓝色 SmartScreen 保护窗：

处置步骤：
  1. 点击弹窗中的「更多信息」(More info) 超链接；
  2. 右下角将出现「仍要运行」(Run anyway) 按钮，点击即可正常安装；
  3. 企业 IT 管理员推荐直接使用 .msi 静默分发包。
macOS Apple Silicon

Gatekeeper 提示“已损坏”或“未能验证开发者”

macOS 针对未经过苹果付费公证的第三方开源程序会自动赋予 com.apple.quarantine 隔离标记：

处置步骤：
  1. 将 Nexus 拖拽到「应用程序」目录；
  2. 打开 Mac 终端 (Terminal)，执行如下一行清除隔离属性命令：
xattr -cr /Applications/Nexus.app

之后即可像普通应用一样直接双击流畅启动。

Linux (Ubuntu / Debian / Arch)

AppImage 运行无反应或提示缺少 libfuse.so.2

在现代 Linux 系统上（如 Ubuntu 22.04+ 或 Fedora），由于默认精简了旧版 FUSE 库，运行 AppImage 前需要确保权限和 FUSE 支持：

处置步骤：
  1. 赋予执行权限：chmod +x Nexus_1.2.0_amd64.AppImage
  2. 若提示缺少 FUSE，Debian/Ubuntu 执行：
sudo apt install libfuse2

或者直接下载 .deb 官方包使用 sudo dpkg -i Nexus_1.2.0_amd64.deb 进行系统级原生安装。

下载与安全常见疑问

绝无任何后门与私有数据泄露。Nexus 完全采用 Apache-2.0 开源许可证在 GitHub 上公开源代码。Nexus 本地服务端仅监听在 127.0.0.1 回环地址上，Server 本身绝不直接读取物理磁盘，所有文件读写均需经过你显式授权的项目沙箱，且敏感凭据（如 .env、私钥 *.pem）受默认物理阻隔墙保护。
本官网提供两种下载路径：1. 「本地高速下载」直接由本地或官网 CDN 极速直连传输；2. 「GitHub 镜像」指向官方 GitHub Releases 分发源。如果其中一个源受到网络波动影响，可随时切换到另一个镜像源进行下载。
Windows 平台推荐下载 企业 MSI 静默安装包 (.msi)。支持管理员通过标准命令 msiexec /i Nexus_1.2.0_x64_en-US.msi /quiet /qn 进行完全无弹窗静默部署，完美契合企业 Active Directory 组策略或 SCCM / Intune 自动化分发工具。
