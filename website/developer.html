DEVELOPER INFRASTRUCTURE · MCP SPECIFICATION v1.20.0

Build on Deterministic Execution Infrastructure

Nexus is a developer-grade Universal MCP Execution Infrastructure—not a chatbot wrapper. Built for ChatGPT Web (with additional WebAI platforms coming soon), it provides a standard Model Context Protocol gateway, extensible Provider SDKs, JobObject isolation, and programmable Action Ledger APIs.

Execution ≠ Success=true. Evidence certifies reality.

Universal MCP Gateway

Exposes standard SSE and HTTP JSON-RPC 2.0 endpoints on 127.0.0.1:18080/mcp, automatically broadcasting registered tool contracts and schemas to the ChatGPT Web bridge and MCP clients.

ENDPOINT: /mcp · TRANSPORT: SSE / stdio / HTTP

Tool Registry

Enforces strongly-typed JSON Schema Draft 7 contracts. Every tool carries a self-describing risk tier (Safe / Caution / Dangerous) and strict parameter bounds.

VALIDATION: AJV · STRICT: true · TYPING: TypeScript

Custom Provider API

Built for third-party extensibility. Connect embedded hardware boards, CAD modeling suites, or internal enterprise databases by implementing the unified Provider interface.

INTERFACE: INexusProvider · EXTENSIBLE: Yes

Runner (JobObject Isolation)

Hardware-backed Windows JobObject process pools ensure child process lifecycles are strictly bounded—preventing memory leaks, zombie processes, and runaway loops.

QUOTA: Memory & CPU · TIMEOUT: CancelToken

Verification Hooks

Post-execution assertion hooks automatically query low-level OS APIs after tool completion—verifying file sizes, SHA-256 digests, and HWND window states before issuing receipts.

ASSERTIONS: File / Process / Window / DOM

Action Ledger Logs

Stream Action Ledger logs in real time via local REST and WebSocket endpoints, or query historical receipts by Action ID, tool name, or timestamp for forensic auditing.

FORMAT: JSON WAL · STREAM: WebSocket /sse
SDK Code Examples

Developer SDK Integration Examples

TypeScript / Node.js SDK

Connect to the local execution bridge and invoke tools with automatic world-state verification:

import { NexusClient } from "@nexus/sdk";

const client = new NexusClient({
  endpoint: "http://127.0.0.1:18080",
  token: process.env.NEXUS_CLIENT_TOKEN,
  verifyWorldState: true,
});

// Execute a sandboxed file write with two-phase verification
const result = await client.execute({
  tool: "filesystem.write",
  parameters: {
    path: "workspace/output/report.docx",
    content: bufferData,
  },
  idempotencyToken: "TASK-8921-CHUNK-01"
});

console.log("Action ID:", result.actionId);
console.log("Verified:", result.verification.pass);
console.log("SHA-256 Digest:", result.worldState.sha256);

Python SDK (Autonomous Agent Harness)

Mount the Nexus Execution Harness from Python scripts or automation pipelines:

from nexus import NexusHarness

harness = NexusHarness(
    endpoint="http://127.0.0.1:18080",
    client_token=os.getenv("NEXUS_TOKEN")
)

# Dynamically discover all registered MCP tool contracts
tools = harness.get_mcp_tools()

# Dispatch execution to Nexus and inspect physical evidence
evidence = harness.invoke(
    tool_name="application.launch",
    arguments={"executable": "blender.exe", "args": ["--background"]}
)

assert evidence.verified is True
print(f"Blender HWND: {evidence.world_state['hwnd']}")
